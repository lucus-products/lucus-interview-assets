迷你阅读器

滚动正文：右边目录会跟着高亮当前小节。打开底部控制台，每换一节都会打印一条日志。

一、为什么要目录

长文里读者需要知道自己读到哪，也需要能一键跳回某一节。

这一页把「正文 + 目录」压缩成一个最小例子：左边滚，右边亮。

二、怎么判断当前小节

正文滚动时逐个看标题的位置：谁在「视口 25% 线」上方、且离它最近，谁就是当前小节。

按位置判断比「IntersectionObserver + 窄带」更稳：沙箱 iframe 没有同源， rootMargin 会被浏览器忽略，窄带退化成整个视口，高亮就会跳到下一节。

三、完整写法

滚动事件很密，用 requestAnimationFrame 合并：一帧最多算一次位置， 避免每个 scroll 回调都强制浏览器重新布局。

点击目录项跳转后，滚动事件会触发一次更新，高亮自动对齐到目标小节。

四、还能怎么扩展

平滑滚动、阅读进度条、记住上次读到哪……都能在这一份骨架上继续搭。

站点右侧的文章目录就是这个思路的完整版，还多了层级缩进和滚动跟随。
